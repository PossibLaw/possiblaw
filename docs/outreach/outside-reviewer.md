# Outreach Template — Outside Reviewer

Use this template when reaching out to a developer who has not contributed to PossibLaw and is willing to follow the extending docs and report what's unclear.

**Replace all `[bracketed]` items before sending.**

---

**Subject:** Would you review our extending docs and tell me what's confusing?

Hi [Name],

I'm working on a project called PossibLaw — an open-source proof-of-concept for running a legal practice with AI agents. I'm at the point where I need an outside developer to read our contribution docs and tell me what's unclear.

The ask is specific: follow one or more of the guides in `docs/extending/` (there are five: add a specialist, workflow, test, guardrail, or connector) and report back on anything that stopped you or made you have to read twice. You don't need to build anything legal. You can add a nonsense agent or a trivial workflow just to exercise the path.

The guides are designed to be self-contained — you shouldn't need to read the full plan. If you do need to read something outside the guide to complete it, that's a finding I want to know about.

Rough time: 1–2 hours depending on how many guides you try. I'm happy to answer questions on a call or async. You'd be listed in the project acknowledgements.

Repo: https://github.com/PossibLaw/possiblaw
Extending docs: `docs/extending/`
Getting-started: `docs/getting-started.md`

Let me know if you're up for it, and which guide(s) you'd like to try.
