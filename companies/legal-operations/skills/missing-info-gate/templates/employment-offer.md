# Employment Offer Letter — Required Fact Template

Use this table when the matter type is an employment offer letter or onboarding agreement. Several fields here are jurisdiction-sensitive; if the work-location state or country is missing, gate on it before resolving anything else, because acceptable defaults differ by jurisdiction.

| Field | Why it matters | Acceptable inputs | Default if any |
| --- | --- | --- | --- |
| Employer legal entity | The offer must be made by the entity that will actually employ and pay the candidate; mismatch creates joint-employer and tax-withholding issues. | Full registered legal name | NO DEFAULT |
| Employer state / country of operation | Drives at-will doctrine, restrictive-covenant enforceability, wage-and-hour rules, paid-leave entitlements, and required offer-letter disclosures. | US state or country; if multi-state employer, the state where the candidate will primarily work | NO DEFAULT |
| Candidate full legal name | Required for the contracting party and for background-check and onboarding records. | Full legal name as it will appear on I-9 or local equivalent | NO DEFAULT |
| Position title | Defines role, FLSA exemption analysis, and equity-tier eligibility. | Job title | NO DEFAULT |
| Reporting manager | Operational clarity and, for some jurisdictions, required in the written offer. | Name and title of direct manager | NO DEFAULT |
| Start date | Triggers benefits eligibility, equity vesting commencement, and onboarding workflow. | ISO date `YYYY-MM-DD` | NO DEFAULT |
| Employment classification | Determines tax treatment, benefits eligibility, overtime exposure, and which form of agreement to issue. | `W-2 full-time`, `W-2 part-time`, `1099 independent contractor`, `intern (paid)`, `intern (unpaid — confirm DOL six-factor test)` | NO DEFAULT |
| FLSA exemption status (W-2 only) | Determines overtime eligibility; misclassification creates significant wage-claim exposure. | `exempt` or `non-exempt` with brief basis (executive, administrative, professional, computer-employee, outside sales, highly-compensated) | NO DEFAULT |
| Base compensation | Core economic term; required for the offer to be a meaningful offer. | Annual salary or hourly rate, plus currency (e.g. `USD 175,000 / year`, `USD 45.00 / hour`) | NO DEFAULT |
| Pay frequency | Required disclosure in many states (e.g. NY Wage Theft Prevention Act); aligns with payroll. | `weekly`, `bi-weekly`, `semi-monthly`, `monthly` | `bi-weekly` |
| Bonus structure | If discretionary versus formulaic, this materially changes enforceability of expected payout. | Target amount, performance criteria, payment timing, and `discretionary` vs `formulaic` | `none` |
| Equity grant | Materially changes total compensation; type of grant (ISO / NSO / RSU) drives tax treatment and board-approval requirements. | Grant type (`ISO`, `NSO`, `RSU`), number of shares or target value, vesting schedule, cliff | `none` |
| Benefits eligibility class | Required to map candidate into health, retirement, leave, and equity plans. | Plan class name or category | Employer's standard class for the role |
| At-will or fixed term | At-will status must be clearly stated where recognized (most US states); fixed-term creates contract obligations and severance exposure. | `at-will (US)`, `fixed term: <length>`, `indefinite per local law (non-US)` | `at-will (US)` only if employer state is a US at-will state; otherwise NO DEFAULT |
| Probationary period | Common outside the US; in the US, an explicit probationary period can undermine at-will status if drafted carelessly. | Length, or `none` | `none` for US at-will employers; jurisdiction-typical default for non-US |
| Restrictive covenants — non-compete | Enforceability varies sharply by jurisdiction. California (Bus. & Prof. Code §16600), Minnesota (2023 ban), North Dakota, Oklahoma, and others restrict or void non-competes; FTC rulemaking is in flux at the federal level. Drafting an unenforceable non-compete invites litigation. | `none`, or specify scope (geography, duration, activity) — jurisdiction must be specified | `none` if employer state is California, Minnesota, North Dakota, or Oklahoma; NO DEFAULT elsewhere |
| Restrictive covenants — non-solicit | Enforceability also varies; California limits customer non-solicits but generally permits employee non-solicits with caveats. | `none`, `employee non-solicit`, `customer non-solicit`, `both` with duration | `12-month employee non-solicit` outside states that disfavor; NO DEFAULT in California |
| Confidentiality and IP-assignment terms | Almost always required; in California, IP assignment must comply with Labor Code §2870 carve-out (employee's own time, no employer resources, not related to employer's business). | `standard CIIAA`, `custom`, `none` | `standard CIIAA with Labor Code §2870 notice for California-based employees` |
| PTO / leave policy | Accrued PTO is wages in some states (e.g. California — must be paid out at separation); policy choice has financial consequences. | Plan name or summary (accrual rate, cap, payout-on-separation) | Employer's standard PTO plan |
| Background-check contingency | If used, must comply with FCRA (federal) plus state ban-the-box and disclosure rules (e.g. NYC, LA, San Francisco fair-chance ordinances). | `yes — standard FCRA disclosure and authorization`, `no` | `yes — standard FCRA disclosure and authorization` |
| Work authorization | Form I-9 verification is required for US W-2 employees; offer must not promise employment without authorization. | `US work-authorized`, `sponsorship required (specify visa type)`, `non-US` | `US work-authorized` |
| Required jurisdiction-specific disclosures | Many states require pay-rate notice (NY, CA), wage-range posting (CA, CO, WA, NY), paid-sick-leave notice, or sexual-harassment training acknowledgement. | List of disclosures included | Employer state's standard disclosure set |
| Signature authority | Offer must be signed by someone with authority to bind the employer. | Name and title of signatory | NO DEFAULT |
